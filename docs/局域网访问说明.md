# 局域网访问说明（给同事测试用）

## 一、发给同事的地址

    http://192.168.0.178:8200/

- 问答页：http://192.168.0.178:8200/
- 语音页：http://192.168.0.178:8200/asr （可加 `?run=sample` 一键跑示例音频）
- 健康检查：http://192.168.0.178:8200/health

前提：同事的电脑/手机要和你**在同一个局域网**（同一个路由器 / 同一个 WiFi，且网段都是 192.168.0.x）。

## 二、第一次必须做的一步：放行防火墙（要管理员）

Windows 防火墙默认**拦所有入站**，不放行的话同事一定连不上。
用**管理员身份**打开 PowerShell 或 CMD，跑一条：

    :: CMD（管理员）
    netsh advfirewall firewall add rule name="secretary 8200" dir=in action=allow protocol=TCP localport=8200

    # PowerShell（管理员）
    New-NetFirewallRule -DisplayName "secretary 8200" -Direction Inbound -Protocol TCP -LocalPort 8200 -Action Allow -Profile Any

删除规则（不再对外时）：

    netsh advfirewall firewall delete rule name="secretary 8200"

## 三、怎么启动服务

**方式一（推荐）**：双击 `启动局域网服务.bat`
—— 它会设好监听地址、启动服务，并在窗口里打印"同事访问：http://…"，直接把那行发给同事。

**方式二**：命令行

    cd D:\秘书智能体\secretary
    set SECRETARY_HOST=0.0.0.0
    py -X utf8 server.py

默认（不设 `SECRETARY_HOST`）只监听 127.0.0.1，**同事访问不了**。
换端口：`set SECRETARY_PORT=8300`。

## 四、同事打不开时的排查顺序

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 浏览器一直转圈 / 连接超时 | 防火墙没放行 | 做第二节那一步 |
| 连接被拒绝 | 服务没在跑，或监听的是 127.0.0.1 | 看启动窗口有没有打印"同事访问"；用 `netstat -ano \| findstr 8200` 确认是 `0.0.0.0:8200 LISTENING` |
| 昨天能开今天不能 | 本机 IP 变了（DHCP） | 重新看启动窗口打印的地址；或把本机 IP 固定 |
| 同 WiFi 也打不开 | 路由器开了**客户端隔离**（AP isolation） | 换有线，或让同事连你开的手机热点（那时地址会变成热点网段的） |
| 服务窗口一关就断 | 服务是前台进程 | 启动窗口要保持开着 |

## 五、测什么

输入框填**上游信息补全后的问题**（时间、地点已明确），例如：

- `截至2026年9月，随州市全市，情况怎么样`
- `2026年9月随州市全市，线损率是多少？`
- `2026年累计哪个供电所线损率最高？多少？`
- `截至2026年9月，随州市全市，酒店入住率是多少？`（应拒答）
