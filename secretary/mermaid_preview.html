图 3

sequenceDiagram
    autonumber
    participant U as 页面（用户）
    participant S as server.py
    participant ASR as Fun-ASR（百炼）
    participant CMP as 问题补全应用（百炼）
    participant A as agent 循环
    participant L as qwen 模型
    participant D as 知识库 / 业务库
    participant G as 缺口清单

    Note over U,ASR: 可选：语音输入（约 1.1 秒走完五阶段）
    U->>S: POST /api/asr（录音二进制）
    S->>ASR: ① 取上传凭证 → ② 上传 OSS → ③ 提交任务
    ASR-->>S: task_id
    loop ④ 轮询
      S->>ASR: GET /tasks/{task_id}
      ASR-->>S: RUNNING → SUCCEEDED
    end
    S->>ASR: ⑤ 取 transcription_url
    ASR-->>S: 转写文本
    S-->>U: 文本 + 五阶段原始请求/返回

    Note over U,G: 问答
    U->>S: POST /api/ask {question}
    S->>S: 补全缓存查一下？
    alt 缓存未命中
      S->>CMP: input.prompt = 原始问法
      CMP-->>S: 标准问题（7–19 秒）
    else 命中
      S->>S: 直接用缓存（0 ms）
    end
    S->>A: agent.ask(标准问题)
    A->>L: messages + 5 个工具定义
    L-->>A: tool_calls: kb_search → run_sql
    A->>D: 检索口径 / 只读取数
    D-->>A: 切片 / 数据
    A->>L: 带结果再问
    L-->>A: 无 tool_calls（已用过工具）→ 答案
    A-->>S: { answer, trace[], timings, counts }
    S->>G: 答不了？（查不到 / 未核实）→ 落一条
    S-->>U: JSON（左栏回答 / 右栏全过程）
