# 项目管理秘书 · 技能调用接口说明

> 线上地址：`http://47.121.183.81:8200`（无鉴权）。自检 `GET /health` 四个字段都要 true。

## 零、所有接口的共同约定（**先看这段**）

| 约定 | 说明 |
|---|---|
| **`today` 由上游传** | **业务上的"今天"**（`YYYY-MM-DD`）。停留天数、同比、"截至今天"全按它算。不传才退回服务器日期。**定时任务/业务系统必须传**，否则跨天跑数会算出不同天数。 |
| **`scope` 由上游传** | 数据范围（如 `国网随县供电公司`、`文峰供电所`）。**传了就强制按它取数**，会压过系统默认的"全市"。 |
| `account` / `uid` | 触发账号，用于确定身份与范围（如 `xgscwb001`）。 |
| `role` / `profile` | 身份与关注口径（角色不同 → 排序口径不同：财务按金额、运检按风险、领导按总量）。 |
| 返回里的 `today` | 回显本次用的业务日期，便于对账。 |
| 单次耗时 | 定时标题 4–10s；常规问答 10–40s；**明细/分析题可能 60–100s**，上游超时请设 ≥180s。 |

## 一、`POST /api/skill/title` —— 定时任务用这个

**只回一句话标题；无异常也回，绝不空返回。**

请求：

```json
{ "skill_id": "approval-role", "account": "xgscwb001", "today": "2026-09-22", "when": "2026-09-22 08:30" }
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `skill_id` | ✅ | 见下表 |
| `account` | 建议 | 触发账号，决定身份与范围 |
| `today` | **建议** | 业务日期 |
| `when` | 可选 | 触发时刻，仅记录 |
| `scope` | 可选 | 覆盖数据范围 |
| `inputs` | 可选 | 上游推过来的单据数据（`[{"label":"…","value":"…"}]`） |

响应：

```json
{ "skill_id": "approval-role", "name": "各层级审批（不同角色）",
  "status": "abnormal", "count": 13,
  "title": "今天有 13 个项目在县公司财务部审核节点积压超90天",
  "today": "2026-09-22", "triggered_at": "2026-09-22 08:30",
  "account": "xgscwb001", "role": "县公司财务部审核", "scope": "国网随县供电公司",
  "checked_at": "2026-09-22 15:10:00", "elapsed_ms": 4031 }
```

| 字段 | 说明 |
|---|---|
| `status` | `abnormal` 有异常 / `ok` 无异常 / `unknown` 本次判据没取到（**仍不是空返回**） |
| `count` | 命中判据的条数；0 即 ok |
| `title` | **直接展示这一句**；无异常展示什么由你们定 |

定时技能：

| skill_id | 技能 | 账号 | 范围 |
|---|---|---|---|
| `approval-role` | 各层级审批 | `xgscwb001`（随县公司财务部） | 国网随县供电公司 |
| `risk-control` | 风险预控 | `sgscwb`（市公司财务部） | 全市 |
| `flow-monitor` | 项目流程实时监控 | `sz002`（文峰所所长） | 文峰供电所 |
| `progress-alert` | 项目执行进度异常提醒 | `sz009`（均川所所长） | 均川供电所 |

## 二、`POST /api/ask` —— 常规问答（标题之后的明细追问也走它）

请求：

```json
{ "question": "这13个项目都是哪些？分别卡了多久？",
  "today": "2026-09-22", "scope": "国网随县供电公司",
  "session_id": "s_xxx", "uid": "xgscwb001",
  "profile": "你的身份：县公司财务部审核。关注口径：金额与预算余额。",
  "history_turns": 5, "want_page": true }
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `question` | ✅ | 用户原话，**不用补全**（地名/名称/时间由服务确定性地补） |
| `today` | **建议** | 业务日期 |
| `scope` | **建议** | 数据范围（强制）；不传则可能按全市 |
| `session_id` | 建议 | 同一场会话传同一个 → 多轮沿用时间与地点口径 |
| `uid` / `profile` | 建议 | 身份与关注口径 |
| `history_turns` | 可选 | 带最近几轮上下文，默认 5；0 = 不带 |
| `want_page` | 可选 | **显式要分析页面**。不传时只有"分析类"回答才生成；传 true 则任何回答都生成 |

响应（关键字段）：

| 字段 | 说明 |
|---|---|
| `answer` | 回答正文 |
| `today` | 回显业务日期 |
| `scope` | 本次统计口径（时间 + 地点） |
| `qtype` | `分析` / `查数`（**按实际发生的事**判定：回答过程中查过判据才算分析） |
| `page_html` | 分析页面（一整页可渲染的 HTML，含 ECharts）；没生成时为空串 |
| `session_id` / `qa_id` | 会话与本次问答 ID |

## 三、`POST /api/skill/run` —— 手动 / 提交前 / 状态变更类技能

请求：`{skill_id, questions[], inputs[], work_name, from, to, role, scope, today}`
响应：`{skill, answer, trace[], tool_calls, elapsed_ms}`（一整段回答，不生成页面）

## 四、其它

| 接口 | 说明 |
|---|---|
| `GET /health` | 服务与附属能力自检 |
| `GET /api/skills` | 技能清单（文档名 + 标题） |
| `GET /api/triggers`、`/api/statechange` | 技能触发台素材 |
| `GET|POST|DELETE /api/kb/**` | 知识库管理面（上传/删除判据文档） |

## 五、典型调用链（定时提醒 → 明细追问）

```python
today = "2026-09-22"; scope = "国网随县供电公司"
t = post("/api/skill/title", {"skill_id": "approval-role", "account": "xgscwb001", "today": today})
show(t["title"])                                  # 今天有 13 个项目…积压超90天

sid = "s_" + uuid.uuid4().hex[:8]                 # **一场会话**
for q in ["这13个项目都是哪些？分别卡了多久？",
          "今天我先办哪几张？",
          "有没有该到我这儿却没到的？"]:
    r = post("/api/ask", {"question": q, "today": today, "scope": scope,
                          "session_id": sid, "uid": "xgscwb001",
                          "history_turns": 5, "want_page": True})
    show(r["answer"], r.get("page_html"))
```
