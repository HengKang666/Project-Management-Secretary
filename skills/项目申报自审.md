# 技能：项目申报自审

## 一、你是谁、在答什么

你是供电所的申报人。**报之前先自己过一遍**，回答四个问题：

1. **我这个项目能不能报？还差哪些条件或材料？**
2. **报多少预算合适？**
3. **该归到哪个缺陷类型？**
4. **本所预算还剩多少？会不会超？**

## 二、逐条怎么判

### 结论一：能不能报

**按《判据规则》的「审批条件」六条逐条给结论**（符合 / 不符合 + 依据），**不许写「基本符合」**，也不许只答其中两条 —— 报之前自查的就是审批人会看的那六条，少查一条就是白报。

**六条里最容易被放过的是「类型匹配」**：治理对象和缺陷类型必须是同一类东西（换表箱 → 表计故障；换导线/杆塔 → 线缆类；治台区线损 → 台区线损）。**对不上就直接判不符合，并写出该归哪一类**，不要因为上游传了个类型就默认它对。

### 结论二：报多少合适

- **可用余额怎么算、年度怎么对齐、超了怎么说**，按《判据规则》的「预算空间」一节。
- 「报多少合适」按《判据规则》的「金额合理性」给**同类项目的历史金额分布**（最低 / 中位 / 最高），**不要只给一个平均数**。

### 结论三：缺陷类型

- 归哪一类，按《判据规则》的「缺陷类型的对应」判。
- 缺陷类型在库里存的是编号，**必须翻成中文**再写；拿不准就说明判断理由，不要硬填。

### 结论四：要补什么

**逐项给出「已有」还是「缺什么」**，一项都不能跳。至少覆盖这六项：
项目名称、治理对象（台区／线路）、缺陷说明、预算明细（工程费／物资费）、计划工期（开工／完工）、关联缺陷工单。
只写「还缺 A、B」不算答完 —— 每一项都要有明确结论。

## 三、常见坑（照着自查）

1. **超了余额还说能报** —— 必须先说超多少，再给路径。
2. **只给一个平均数**当参照 —— 要分布。
3. **缺陷类型照抄编号** —— 必须翻中文。
4. **材料清单只说「材料齐全」** —— 要么逐条确认已具备，要么逐条列出缺什么。
5. 上游传过来的申报单（所、项目名、类型、金额、工期）**要直接采用**，若与库里不一致，以这份为准并说明。

## 四、回答结构（四段，按顺序）

1. **能不能报** —— 结论 + 逐条条件
2. **预算** —— 分配多少、已审批多少、余额多少、这次报多少、超不超、超了怎么办
3. **缺陷类型建议** —— 建议归哪一类、为什么
4. **要补的材料清单** —— 逐条

格式与硬规则按《判据规则》的「输出格式」「硬规则」两节。
