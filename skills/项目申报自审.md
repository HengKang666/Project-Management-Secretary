# 技能：项目申报自审

## 一、解决什么问题

申报人**点提交之前**，把这一单从头到尾过一遍：能不能报、缺什么、填错没有、改完再交。
**一次触发，触发时点就是「点提交前」。**

**两种角色、两种维度（回答不固化）**：

| 角色 | 关心什么 |
|---|---|
| 录入人员 | **填得对不对**：必填项齐不齐、名称在不在档、格式对不对 |
| 申报人 / 所长 | **能不能报**：钱够不够、类型对不对、来不来得及 |

只填了一半的单子，重点回答「缺什么」；填全了的单子，重点回答「钱和类型对不对」。

## 二、怎么拆（一步一步）

1. **拆必填项清单**，逐项给「已有 / 缺」：项目名称、治理对象（台区 / 线路）、缺陷类型、缺陷说明、预算总额、工程费、物资费、计划开工、计划完工、关联缺陷工单。
2. **名称在不在档**：供电所名、台区名 / 线路名是否在档案里；不在档要指出。
3. **金额自洽**：工程费 + 物资费 与 总额 对不上，差多少。**用精确到元的原值算，差额超过总额 1% 才算真差异**（四舍五入造成的 0.01 万不是差异）。
4. **工期**：开工 ≤ 完工？距今天剩多少天？<45 天偏紧、<20 天不可行；开完工倒挂直接判不符合。
5. **类型匹配**：治理对象与缺陷类型是不是同一类东西（换表箱 → 表计故障；换导线 / 杆塔 → 线缆类；治台区线损 → 台区线损）。对不上要写出该归哪一类。
6. **本所余额**：分配额 − 已审批 = 余额；这单超没超、超多少。**先明说超了多少，再给两条出路**（拆分为余额以内的核心内容 / 申请追加统筹）。
7. **同类金额分布**：同一缺陷类型的历史项目，给样本数 / 最低 / P25 / 中位 / P75 / 最高，并说明这单排在同类的前百分之多少。**只给一个平均数不算答完。**
8. **汇总**：结论（能不能报）+ 逐条缺项 + 逐条填错的 + 对每一项给出怎么改。

## 三、回答模板（严格照着写，这就是最终给人的那段话）

**总长纪律：不超过 250 字。**
**回答只有下面这些内容，不要再换个标题重复一遍。**

结论：不能报。本所 2026 年余额 48.20 万元，这单报 50.00 万元，超 1.80 万元。
要改的：
1. 预算明细不平：工程费 32.00 + 物资费 15.00 = 47.00 万元，比总额 50.00 万元少 3.00 万元。
2. 类型不匹配：治理对象是台区低压线路，应归「线缆类-导线」，现填「表计故障」。
3. 工期偏紧：距计划完工 2026-12-31 只剩 3 个多月。
钱：同类型历史项目中位 X 万元（样本 N 个），报 50 万元高于其中位。
建议：压到余额以内、类型改成线缆类-导线、补齐明细，再提交。

**两条硬约束**：
- **不许把 10 个必填项写成 10 段**：已具备的合并成一句「其余必填项已填」，**缺的和错的才逐条列**。
- 结论（能不能报）必须放在第一句。
- **样本 ≥5 且申报额高于同类最高值 → 直接判「明显偏高（是同类中位的 X 倍）」**，不要再写「需人工复核」；**只有样本 <5 才写「需人工复核」**，两者不许混用。

### 各段必须包含的内容


1. **能不能报** —— 结论 + 逐条依据
2. **预算** —— 分配多少、已审批多少、余额多少、这次报多少、超不超、超了怎么办
3. **缺陷类型建议** —— 建议归哪一类、为什么
4. **要补的 / 要改的** —— 逐条，每一项都要有明确结论（已有 或 缺什么）

## 四、回答约束

- **不许写「基本符合」**；不许只说「材料齐全」—— 要么逐条确认已具备，要么逐条列出缺什么。
- 超了余额不许还说「可以报」；必须先说超多少，再给两条出路。
- 缺陷类型必须翻成中文；拿不准就说明判断理由，不要硬填。
- 名称、金额、工期、类型这四项**一项都不能跳**。
- 清单逐条列全，不许「等」「其余」。

格式与硬规则按《判据规则》「十五、输出格式」「十六、硬规则」；判断标准按「四、预算空间」「五、审批条件」「六、缺陷类型的对应」「九、金额合理性」。
