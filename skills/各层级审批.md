# 技能：各层级审批（不同角色）

## 一、解决什么问题

每个审批角色**上班先看自己这一级**：有没有项目卡在我这个阶段、有没有超时的、有没有漏掉的。
**不同角色 = 不同范围 + 不同关注口径**，回答结构固定、内容随角色变。

| 角色 | 范围 | 关注口径（问题排序按这个） |
|---|---|---|
| 所长（供电所内部审核） | 本所 | 内容真实性、治理对象与缺陷类型是否匹配 |
| 县公司运检部审核 | 本县公司下各所 | 专业、技术可行性、施工风险 |
| 营销部审核 | 按专业分流的单 | 是否营销类、客户侧影响 |
| 县公司财务部审核 | 本县公司 | 金额、预算余额、明细是否平 |
| 市公司财务部审核 | 全市 | 金额、余额、跨县对比 |
| 市公司领导审批 | 全市 | 总量、积压、风险 |

## 二、怎么拆（一步一步）

1. **先定范围**：所长 = 本所；县公司部门 = 本县公司下各所；市公司 = 全市。
2. **查停在我这个节点的单**（审批任务表里只有「待处理」状态才算待办，已完成 / 已驳回 / 处理中都不算），逐单算停留天数 = **系统当天 − 进入本节点的时间**。
3. **分档**：≤15 天正常 / 16–90 天偏慢 / >90 天积压。
4. **找遗漏**：同一张工单，上一节点已完成且未驳回，但本节点没有生成待处理任务 → 判「遗漏」。
5. **按我的关注口径排先后**：财务按金额、运检按风险、领导按总量。
6. **汇总**：我这一级多少张、合计多少钱、最久的几张、遗漏几张、今天先办哪几张。

## 三、回答模板（严格照着写，这就是最终给人的那段话）

**总长纪律：不超过 300 字。**
**回答只有下面这些内容，不要再换个标题重复一遍。**

截至 2026 年 9 月 16 日，您（县公司财务部审核）这一级有 13 张待处理、合计 X 万元，其中积压（>90 天）N 张。
最久的 3 张：白鹤湾6#台区_下户线过细、老化严重｜淮河供电所｜1.55 万元｜停留 152 天；…
遗漏：N 张（上一节点已通过、未生成您的待办）：…；没有就写一句「无遗漏」。
今天先办：先办停留最久的 X、金额最大的 Y。

**两条硬约束**：
- 「N 张」必须和列出的条数一致；停留天数一律算到系统当天。
- **概览里的分档条数，必须和逐条清单里每条的分档对得上** —— 上面说「积压 1 张」，下面就绝不能出现一条标着「偏慢」；对不上就是有一处算错了，回去核。
- **不要把所有单据都列出来**：超过 30 张就列前 20 张并写「其余 N 张合计 X 万元」；10 张以内可以全列。

### 各段必须包含的内容


1. **概览** —— 截至今天，我这一级 N 张待处理、合计 X 万元，各档几张
2. **最久的清单** —— 逐条：工单名 / 所属所 / 金额 / 停留天数 / 超了哪一档
3. **遗漏的** —— 逐条：哪张单、卡在哪个节点、为什么没到我这儿
4. **今天先办哪几张** —— 按我的口径排序，说清为什么先办它

## 四、回答约束

- 必须以「截至 X 年 X 月 X 日」开头。
- **不许按创建年度过滤** —— 卡最久的往往就是往年创建的项目，滤掉正好把最该清的藏起来；要在回答里写明「含往年创建」。
- **严禁把全库「审核中」的量当成某一个角色的待办**；只给提问人这一个环节的。
- 停留天数一律算到系统当天；**不许把收到的变更时间当今天**（否则刚转来的件会被算成「停留不足 1 天」）。
- 必须点名具体单据，不许只说「存在积压」；数量与列出的条数必须一致。
- 报完积压还要报遗漏 —— **积压 = 停在我这里没动的；遗漏 = 该到我却没到我这儿的**，两件事分开说。

格式与硬规则按《判据规则》「十五、输出格式」「十六、硬规则」；判断标准按「八、审批停留」「十二、角色 → 可见范围」「十七 17.3」「十七 17.6」。
