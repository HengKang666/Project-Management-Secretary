# 技能：风险预控

## 一、解决什么问题

**每天自己跑一遍，专门把我可能漏判的资金问题捞出来。**

- **已经批出去的申请**：回头核查 —— 当时批的时候，有没有漏看资金合理性。
- **今天新进来的申请**：提前体检 —— 别等批完了才发现钱不对。

**扫的是已通过的 + 新增的，不是在审的。**

**不同角色、不同范围（回答不固化）**：

| 角色 | 范围 | 看什么 |
|---|---|---|
| 市 / 县公司财务 | 全市 / 本公司 | 今天全市发现几张资金不合理的、涉及哪些所 |
| 所长 | 本所 | 本所的单有没有被标出来 |

## 二、怎么拆（一步一步）

1. **取单**：当天新增的申请 + 当年已通过的单，按角色范围取。
2. **对每一单找同类**：先同所 + 同缺陷类型 + 近两年；样本不足 5 个退到同公司；再不足才退到全市。**三档都要报数，写明为什么退档。**
   **三档的样本数必须分别来自三次独立统计**：同所同类型 N 个、同公司同类型 M 个、全市同类型 K 个。**不许拿同所的数字冒充全市**（实测：府河供电所一张「线缆类-导线」的 25.65 万元工单，同所同类只有几条，但全市同类有 62 条、最高 31.99 万元）。
   **先选实际样本量最大的那一档下结论**；每档中位数都要单独算，不许把不同档的中位数混用。
   **样本不足 5 个的那些单，不要写进「发现资金明显不合理 N 张」里** —— 单独一句「另有 N 张金额偏离较大但样本不足，需人工复核」。
3. **算同类的金额分布**：样本数 / 最低 / P25 / 中位 / P75 / 最高。**必须给分布，不许只给一个平均数。**
4. **比这一单**：**按《判据规则》第九节** —— 高于同类历史最高值、或高于同类中位数 2 倍 → 判明显偏高；低于 P25 的一半 → 明显偏低。
   **这是硬线，只要命中就判「明显偏高」** —— 不许用「样本充足」「分布离散度大」「行业差异」这类理由把它解释掉。三档只决定**样本量够不够**，**不改变阈值**。
   （实测参照：府河供电所一张 25.65 万元的线缆类工单，同类中位 0.96 万元 ＝ 中位的 26.7 倍，**必须判明显偏高**。）
5. **看结构**：工程费 / 物资费的比例与同类中位数偏离 ±50% → 结构异常。
6. **样本不足 5 个不许下结论**：只陈述事实（例如「高于已查得的 N 个同类项目的最高值 X 万元」）+ 写「需人工复核」。**不许既说偏高又说无法判定。**
7. **汇总时必须分开报**：已通过的单里发现 N 张（= 漏判）、新增的单里发现 M 张（= 待判）。
8. **说「偏高」必须写清拿哪几个同类项目比的。**

## 三、回答模板（严格照着写，这就是最终给人的那段话）

**总长纪律：不超过 250 字。**
**回答只有下面这些内容，不要再换个标题重复一遍。**

今天扫了已通过 21 张、新增 3 张，发现资金明显不合理 2 张（已通过 1 张＝漏判、新增 1 张＝待判）。
1. 【漏判·已通过】响水桥5#台区拆除低压电缆｜文峰供电所｜4.53 万元｜同类 62 个、中位 1.38 万元｜是同类中位的 3.3 倍。
2. 【待判·新增】…（同类样本少于 5 个的，只陈述事实并写「需人工复核」）。
建议核实：先看第 1 张 —— 它已经批出去了，同类样本充足、偏离明显。

**两条硬约束**：
- **每张一行**，不要一段一张。
- 已通过（漏判）和新增（待判）必须分开标。

### 各段必须包含的内容


1. **概览** —— 今天扫了已通过 X 张、新增 Y 张；发现资金明显不合理 N 张（其中漏判 N1、待判 N2）
2. **逐张** —— 单名 / 所属所 / 申报金额 / 同类样本数 / 同类中位与最高 / 偏高多少 / 结构有没有异常
3. **建议核实哪几张** —— 按偏离幅度排序，说清该谁去看

## 四、回答约束

- **必须区分「已通过（漏判）」和「新增（待判）」**，不许混成一堆。
- 每张都要给**同类样本数**；样本不足 5 个不许下「不合理」的结论。
- 可比范围**一档一档来，不许跳档** —— 跳档会改变结论（实测同一张单换档后从「离群」变「合理」）。**每一档都要报数**：同所同类型 N 个 → 同公司 M 个 → 本次按【哪一档】比、样本 K 个；只写「同类」不写档位算没答完。
- 金额一律用精确到元的原值参与计算，展示时才折成万元。
- 没发现问题就明确写「今天未发现资金明显不合理的申请」，**不许为了凑内容编一张出来**。

格式与硬规则按《判据规则》「十五、输出格式」「十六、硬规则」；判断标准按「九、金额合理性」「十、数据质量」「十七 17.4」。
