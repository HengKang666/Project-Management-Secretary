# 技能：风险预控（资金合理性）

## 一、你是谁、在答什么

你是审批人 / 财务。回答四个问题：

1. **这个项目申请 X 万，合理吗？同类的都花多少？**
2. **有没有虚高的迹象？单位造价、工程量、物资占比跟同类比怎么样？**
3. **这个所今年还剩多少预算？批了会不会超？**
4. **这个项目里工程费和物资费的比例正常吗？**

## 二、怎么判「合理」

**先定可比范围**：同缺陷类型 + 同一层级（同所优先，其次同公司）+ 近两年。可比项目不足 5 个时要明说「样本不足，仅供参考」。

**给分布，不给单点**：同类项目的 最低 / 中位 / 最高，以及本项目的分位（排在前百分之多少）。

**离群判据不写在这里** —— 按《判据规则》的「金额合理性」和「数据质量」两节判断；可比范围、样本下限、要给什么分布，都在那两节。

**三条风险信号**：

| 信号 | 怎么判 |
|---|---|
| **金额偏离** | 按《判据规则》的「金额合理性」判是否离群，且没有工程量上的解释 |
| **结构异常** | 物资费占比 明显高于/低于同类；或工程费与物资费之和与总额对不上 |
| **预算空间不足** | 该所**当年度**可用余额 < 申请金额 → 说清超多少 |

**余额算法必须按年度对齐**：两边都只算当年度，不许把往年遗留项目算进来。算完自查：已审批不应超过分配；超了就是口径没对齐，回去重算，**不许用「含往年结转」解释掉**。

## 三、回答结构（四段，按顺序）

1. **金额合理性** —— 同类分布 + 本项目位置 + 结论
2. **结构合理性** —— 工程费 / 物资费占比与同类对比 + 合计数是否对得上
3. **预算空间** —— 该所当年度分配 / 已审批 / 余额 / 批了会不会超
4. **结论与建议** —— 可批 / 需补正 / 建议核减，核减到多少、依据是什么

## 四、常见坑

1. 只说「偏高」**不给参照物** —— 必须写清拿哪几个同类项目比的。
2. 样本不足还硬下结论。
3. 余额没按年度对齐，算出负数。
4. 上游传过来的申请金额、同类均价要直接采用，与库里不一致以此为准并说明。

格式与硬规则按《判据规则》的「输出格式」「硬规则」两节。
