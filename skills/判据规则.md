# 判据规则（所有技能共用）

> **这一份是判断标准的唯一出处。** 技能文档只写「按本文的判据判断」，**不重复具体数值**。
> 数值是按实测定的起始值，业务方定了正式口径就改这里，**不用改任何技能文档**。
> 改动只需改这一处，所有技能同时生效。

---

## 0. 前置：所有统计一律先按年度过滤

只看**当年度创建**的项目。**依据**：实测历史遗留让「审核中」工单平均年龄达 **1422 天**、超期项目平均 **1221 天** —— 不按年度，当期信号会被历史垃圾完全淹没。

## 1. 预算执行

| 项 | 值 | 说明 |
|---|---|---|
| 「已审批」口径 | 状态为 **审核通过待施工 / 施工中 / 施工完成待验收** 的工单 | 草稿、提交审核、审核中、已驳回、已取消 **不算** |
| 「未审批」口径 | 草稿 / 提交审核 / 审核中 / 驳回已修改 | 不含已驳回、已取消 |
| **强制自查** | 预算使用占比 **必须 ≤ 100%** | 超了就是口径没对齐（多半混了往年项目），回去重算；**不许用「含往年结转」解释掉** |

**2026 年基准值（用于校验）**：分配 **1880.00 万** ／ 已审批 **128.08 万** ／ 占比 **6.81%**。

## 2. 进度异常

| 异常 | 起始判据 | 分档 |
|---|---|---|
| 超期 | 已过计划完工日 **15 天**以上仍未完工 | 15–30 / 31–90 / 90 天以上 |
| 落后 | 已过计划工期一半，状态仍停在「审核通过待施工」之前 | 落后一档 / 两档 |
| 停滞 | 状态长期未变 | 停滞 30 天以上 |
| 钱花了没动 | 金额较大且长期停在待施工/施工中 | 按金额取前几位 |

**计划完工日缺失的处理**：实测 **5266/5313（99%）** 没填 → **缺就写「无法判定」，不设占比阈值、也不当异常**，同时把缺失数量作为数据质量反馈报出。

## 3. 审批停留（积压）

| 档 | 天数 |
|---|---|
| 正常 | ≤ 15 天 |
| 偏慢 | 16–90 天 |
| **积压** | **> 90 天** |

**依据**：历史遗留工单平均年龄 1422 天，均值不可用，先用季度口径起步。

## 4. 金额合理性（离群判据）

- 申请金额 **高于同类历史最高值**，或 **高于同类中位数 2 倍** → 判**离群**，必须给出可比项目清单。
- 可比范围：**同缺陷类型 + 同一层级（同所优先，其次同公司）+ 近两年**；可比样本 **少于 5 个**要明说「样本不足，仅供参考」。
- 实测参照：线缆类-杆塔 平均 3.43 万、最高 32.52 万。

## 5. 数据质量判据

| 项 | 判据 | 依据 |
|---|---|---|
| 物资费占比 | **< 0% 或 > 100%** → 判数据异常 | 实测出现过 **224%**（物资费 > 总额） |
| 计划完工日缺失 | **只看数量，不设占比阈值** | 实测缺失 99% |

## 6. 实时监控阈值

| 指标 | 起始阈值 | 提醒对象 |
|---|---|---|
| 预算执行率 | 低于 **已过时间 × 0.6** | 对应供电所 + 县公司财务 |
| 审批停留 | 超过 **90 天** | 卡住的那个审批节点 |
| 超期未完工项目 | 超计划完工日 **15 天以上** | 项目负责人 + 所属县公司 |
| 物资费占比异常 | <0% 或 >100% | 数据维护方 |
| 计划完工日缺失 | 只看数量 | 数据维护方 |

## 附：这份规则怎么维护

- **改数值**：直接改本文档（业务方定了正式口径就替换掉「起始值」）。
- **加判据**：在对应章节加一行。
- **技能文档不重复这些数值** —— 只写「按《判据规则》判断」。
