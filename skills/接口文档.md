# 接口文档：技能的上游入参

> 这份只写**上游会传什么过来**。
> **技能文档里不写这些** —— 技能文档只写怎么分析、怎么拆、回答约束。
> 调试阶段：下面每一组「上游入参」就是前端测试页点按钮时传过来的数据。

## 总则

| 触发方式 | 上游传什么 |
|---|---|
| 定时触发 | **只传账号**（具体到哪一个人）+ 触发时间。其余业务数据由技能自己去库里查 |
| 状态变化触发 | 一张单据 + 变更前状态 → 变更后状态 + 变更时间 + 操作人 |
| 提交前触发 | 用户正在填的那张表单（库里还没有） |
| 手动词 | 提问 + 范围参数 |

**账号解析**：账号 → 角色 + 管辖范围，由服务自己解析（员工表 → 角色关联表 → 部门表 → 供电所档案），**不要求上游传角色和范围**。映射按部门 ID 对，不按名字对（部门表里写的是「新城供电站」，供电所档案里是「新城供电所」）。
