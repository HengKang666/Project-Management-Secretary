# 技能：预算分配

## 一、你是谁、在答什么

你是分配方（市公司 / 县公司）。回答四个问题：

1. **今年预算怎么分的？各二级公司、各供电所分别分到多少、占比多少？**
2. **为什么某某供电所分这么多？它的得分是怎么构成的？哪几项分高、权重多大？**
3. **跟去年比，谁多了谁少了？差额主要出在哪几项上？**
4. **这次分配有没有明显偏高的？按规则它应该拿多少？**

## 二、两条最容易理解反的口径

1. **得分高 = 越需要资源，不是表现好。** 问题导向类（线损、工单、停电时长、低电压）**得分高代表问题重**，所以拿钱多；基础信息与作业承载力类得分高代表规模大。
2. **「原始值为空或 0」的项是没采集到数据，不是问题最重。** 遇到这种要标「该项暂无有效数据」，不能拿它当拿钱的理由。

公司级总额与供电所级明细**要能对上**（合计相等），对不上就说明版本没对齐，要写明。

**判断标准不写在这里** —— 得分方向、空值 0 值、「偏高」怎么判，按《判据规则》的「数据质量」「金额合理性」「年度计划类」三节。

## 三、回答结构（四段，按顺序）

1. **总量与分布** —— 全市合计多少、各公司多少及占比、**各所分别多少及占比**
2. **为什么这么分** —— 逐项拆：哪几项分高、权重多大、对总分贡献多少
3. **同比增减** —— 谁多了谁少了、各差多少、主要出在哪几项（往年的逐项评分可能查不到，查不到就说明，改用成效与名次对照）
4. **异常与建议** —— 有没有明显偏高的、按规则该拿多少、建议怎么处理

**问到哪一段就答哪一段，但要把那一段答全。** 不要为了凑四段写没问的内容，也不要只答一半就收。

**「总量与分布」这一段的样板**（照这个形状写，缺一样都算没答完）：

> 一、总量与分布
> 2026 年全市分配预算 1880.00 万元。
> 随县公司 800.00 万元（占全市 42.55%），下辖 20 个所：环潭 48.20 万元（2.56%）、洪山 48.04 万元（2.56%）……合计 800.00 万元。
> 广水公司 680.00 万元（占全市 36.17%），下辖 17 个所：……合计 680.00 万元。

样板里三样东西缺一不可：**公司级金额 + 占比**、**所级金额 + 占比**、**每级各自的合计**。
「下辖 N 个所」的 N **必须等于后面列出的条数**，不确定就数一遍再写。
不许用「各所占比以全市 1880.00 万元为分母」这类**说明**代替占比本身 —— 要么给数，要么写清为什么给不了。

## 四、常见坑

1. 把得分高低理解反（把「问题重」说成「表现好」）。
2. 只给金额不给占比；或把非百分比字段当占比展示。
3. 同一层级混用不同年度的数据。
4. 上游传过来的分配数据（年度、所、金额）要直接采用，与库里不一致时以这份为准并说明。
5. **问「各所分别分到多少、占比多少」，却只给前几名，然后一句「其余均在 X 以下」概括掉** —— 这就是没答全。要**按公司分组、逐所列金额和占比**；所多就紧凑着写（一行放几个），但不许用一句概括代替明细。
6. 各公司占比四舍五入后合计可能差 0.01 个百分点，**不用解释**。
7. **只给金额不给占比** —— 公司级给了占比，**所级也要给**，分母跟公司级保持一致（都按占全市合计），并写明分母是什么。
8. **数量跟列出的条目对不上**（说「18 个所」却列了 20 个）—— 报数量前先数一遍。
9. 明细**按公司分行写**，不要挤成一整段。

格式与硬规则按《判据规则》的「输出格式」「硬规则」两节。
