# 技能：审批

## 一、解决什么问题

一张申请**到了我手上**，按规则判它**能不能通过**。回答的是「逐条符不符合 + 建议过还是退」，不是复述这张单。

**同一套规则，侧重随角色变（回答不固化）**：

| 角色 | 先看什么 |
|---|---|
| 所长 | 内容真实、治理对象与缺陷类型是否匹配 |
| 县公司运检部审核 | 专业、技术可行性 |
| 营销部审核 | 是否营销类、客户侧影响 |
| 县 / 市公司财务部审核 | 金额、预算余额、明细是否平 |
| 市公司领导审批 | 总量与合规 |

## 二、怎么拆（一步一步）

1. **取出这张单的全部要件**：工单名、治理对象、缺陷类型、缺陷说明、预算总额、工程费、物资费、计划开工、计划完工、关联缺陷工单。
2. **逐条对规则**（六条，一条都不许跳）：
   1. 有工单载体 —— 每笔预算都有对应的缺陷工单
   2. 预算装得下 —— 该所当年度可用余额 ≥ 申报金额
   3. 类型匹配 —— 治理对象与缺陷类型一致
   4. 明细完整 —— 工程费、物资费都填了，且工程费 + 物资费 = 总额（用精确到元的原值；真差异判据是差额 > 总额的 1%）
   5. 工期合理 —— 有计划开完工时间，跨年的要有说明
   6. 金额可比 —— **按《判据规则》第九节判**：高于同类历史最高值、或高于同类中位数 2 倍 → 判**不符合（离群）**
3. **每条给「符合 / 不符合 / 无法判定 + 依据」**，依据必须能追到具体数或字典。
4. **按我的角色侧重排先后**（财务把金额问题放前面，运检把类型与技术问题放前面）。
5. **出结论**：建议通过 / 建议退回（写明理由）/ 无法判定（写明缺什么）。

## 三、回答模板（严格照着写，这就是最终给人的那段话）

**总长纪律：不超过 300 字，六条各一行。**
**回答只有下面这些内容，不要再换个标题重复一遍。**

结论：建议退回。
1. 有工单载体：符合（徐咀3#台区）。
2. 预算装得下：符合（余额 X 万元 ≥ 7.50 万元）。
3. 类型匹配：符合（线缆类-电缆 对应更换电缆）。
4. 明细完整：符合（33 671.95 + 41 278.49 = 74 950.44 元）。
5. 工期合理：无法判定 —— 计划开完工两个字段都是空的（全库 99% 如此），这是数据缺失，不是项目不合格。
6. 金额可比：符合（同类中位 X 万元，本项目 7.50 万元）。
退回理由：把计划工期补上再提交。

**两条硬约束**：
- **六条各一行**，不许展开成段。
- 结论只有三种；**结论必须和依据一致**，依据写「对得上」就不能标不符合。

## 四、回答约束

- **一律不许写「基本符合」。**
- 结论只有三种：符合 / 不符合 / 无法判定；**结论必须和后面的依据一致** —— 依据里写「未超余额」就不能标不符合，写「差异对得上」就不能标不符合。
- **六条里只要有一条是「无法判定」，总结论必须带上这个尾巴**（例：建议通过（工期一项因数据缺失无法判定，建议补齐后归档）），不许写成光秃秃的「建议通过」。
- **命中离群判据（高于同类最高值，或高于中位 2 倍）就直接判不符合，不要写成「需人工复核」** —— 「需人工复核」只在样本不足 5 个时用。金额可比这条必须写清**三档样本数**：同所同类型 N 个 → 同公司 M 个 → 本次按【哪一档】比、样本 K 个。**只写「全市」而不说前两档有几个，算没答完**；样本 <5 只说事实 + 需人工复核。
- 「无法判定」要说清**是数据没有，不是项目不合格**（例如工期字段全库 99% 是空的）。
- 缺数据不许编；拿不准就标无法判定，**不要先写一个不符合再圆回来**。
- 编号一律翻中文。

格式与硬规则按《判据规则》「十五、输出格式」「十六、硬规则」；判断标准按「四、预算空间」「五、审批条件」「六、缺陷类型的对应」「九、金额合理性」「十七 17.6」。
